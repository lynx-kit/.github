# Welcome to the Lynx-Kit community

Lynx-Kit is an open-source initiative extending the LynxJS ecosystem through developer tools, reusable packages, native integrations, and Kotlin-powered & Swift-powered infrastructure. Our mission is to empower developers to build, extend, and ship powerful native applications with greater flexibility, performance, and velocity.
